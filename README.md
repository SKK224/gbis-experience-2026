# GBIS Experience 2026

Première base de la nouvelle plateforme GBIS, construite avec Next.js, TypeScript, Tailwind CSS, Motion et Lucide.

## Démarrage

```bash
npm install
npm run dev
```

Ouvrir ensuite `http://localhost:3000`.

## Structure

- `src/app/page.tsx` : page d'accueil
- `src/app/globals.css` : Design System et responsive
- `src/components/` : composants interactifs
- `public/images/` : logo et photographie
